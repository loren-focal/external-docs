Installer Packet

Everything you need to install Focal heaters, in order. Work straight through the sequence below.

Scan for the live guides Always the current version, with search and full-size diagrams. Opens to the installer sequence.
  1. Safety & Clearances: read before touching hardware
  2. Set Up Network: connect the Focal Point box and access point
  3. Install Rails: mount and plug in the rails
  4. Install Heaters: slide each heater onto the rail
  5. Assign Heaters: match the app to the physical layout

Reference sections follow: Heater Control, Troubleshooting, Warranty & Support.

Before you begin

  • Site plan and this packet on hand
  • Mounting surface can hold 300 lb
  • Dedicated GFCI outlet on the cord-exit side of each rail
  • Rail and heater counts match the site plan
  • Focal Point box and access point
  • Focal Control link and password from Focal
  • A phone with a camera and internet

Before you leave

  • All rails level, drop pipes vertical, swing under 1/4"
  • Every heater seated and powering on with LEDs lit
  • Cables routed and hidden, nothing below the rail
  • Every heater online in Focal Control
  • Zone map matches the physical layout, verified heater by heater
  • Customer walked through Heater Control basics
