## Confirm before you start

Focal sends a site plan for every job. It specifies rail locations and lengths, the access point location, and the zone layout. Work from it, and note any change you have to make.

{% include checklist.html items="Site plan on hand | Rail and heater counts match the site plan | Focal Point box and access point on hand | Focal Control link and password from Focal | A phone with a camera and internet | Mounting surface can support 300 lb | A dedicated GFCI outlet installed on the cord-exit side of each rail" %}

## Parts and terms

| Term | What it means |
|---|---|
| Rail | The powered aluminum extrusion the heaters hang from |
| Heater (Duo) | One unit with two heating nodes, one per side |
| Node | A single 300W heating element, one per side of the heater |
| Slot | A position on the rail where a heater seats and gets power |
| Plug point | The contact inside the slot that powers the heater |
| Spacer | Sits between heaters to hold spacing on the rail |
| Bumper | The end trim that covers the end cap screws |
| Pull string | The string under the heater. A short pull changes heat level, a full pull releases the heater from the rail |
| QR tag | The round tag on the heater labeled SCAN TO HEAT, used to assign and to control |
| Zone | A group of rails controlled together, defined on the site plan |
