## Before you start

The rail should already be mounted, plugged in, and switched on. Heaters load from the end opposite the power cord and seat into plug points along the rail.

Check the site plan for how many heaters go on this rail. Never exceed the maximum for the rail length: 2 on a DRL-04, 3 on a DRL-06 or DRL-08.

## Install each heater
