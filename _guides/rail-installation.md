## Before you start

Read [Safety & Clearances]({{ site.baseurl }}/safety-and-clearances/) first. It covers the clearances this install has to meet.

Confirm each rail's location and length against the site plan before you mount anything.

{% include dodont.html do="Confirm the mounting surface is solid and can hold 300 lb." dont="Mount to anything that flexes or isn't rated for the load." %}

{% include warn.html text="Do not power on the rail until mounting is complete and clearances are verified." %}

## Rail lengths

| Rail | Nominal | Max heaters | Max current | Plug | Receptacle |
|---|---|---|---|---|---|
| DRL-04 | 4 ft | 2 | 15A | NEMA 5-15P | NEMA 5-15R |
| DRL-06 | 6 ft | 3 | 20A | NEMA 5-20P | NEMA 5-20R |
| DRL-08 | 8 ft | 3 | 20A | NEMA 5-20P | NEMA 5-20R |

Each rail has a T-slot running its full length and an 8-foot built-in power cable. Focal supplies mounting hardware, but off-the-shelf hardware works as long as it connects through the T-slot.

## What's in the mounting kit

Every rail ships with two pre-built rail attachment assemblies, two overhead mounting blocks, and fastener options for whichever structure you're mounting to. Use the fasteners that suit the site and leave the rest.

| Part | Qty | Use |
|---|---|---|
| Rail attachment assembly, pre-built | 2 | Slides into the T-slot. The rail hangs from these |
| Parallel mounting bracket | 2 | Ceiling mount, underside of an overhead member |
| Perpendicular mounting bracket | 2 | Beam or joist mount, vertical face |
| Dropdown pipe, 6 ft | as needed | Cut to your drop length |
| Set screw, 1/4-20 x 5/16" | 4 | Clamps the pipe into the block |
| Flat-head screw, 1/4-20 x 1.5" / 2.5" / 3.5" | 4 each | Through-mounting, with washer and lock nut |
| SAE washer, 1/4" ID | 4 | Through-mounting |
| Nylon lock nut, 1/4-20 | 4 | Through-mounting, far side |
| Wood screw, #12 x 2" / 3" | 4 each | Solid wood where you can't reach the far side |

Tools included: 1/8" L-wrench for set screws, T30 L-wrench for 1/4-20 flat-head screws, T25 bit for wood screws.

## Rail placement over the table

Run the rail down the center of the table so heat lands on the middle of each guest's chest, not the top of their head. If the rail has to sit off-center, angle the heaters toward the guests, but not far enough that they only warm heads.

## Mount the rail

{% include step.html number="1" title="Slide the blocks onto the rail" body="Slide at least two mounting blocks onto the rail without tightening, each about 12\" from a rail end. Point the set screws toward the same side as the power cord exit." diagram="rail-01-slide-block.png" %}

{% include step.html number="2" title="Fix the brackets to the structure" body="Fasten with #12 wood screws (2\" or longer) into solid wood, or through-mount with the longer 1/4-20 flat-head screws, SAE washers, and nylon lock nuts. Use 2A or 2B below, whichever matches the structure. Repeat at least twice per rail and match the drop length so the rail hangs level." %}

{% include step.html number="2A" title="Ceiling mount" body="Use this where you can fasten to the underside of an overhead member. Fix a parallel mounting bracket to the structure, slide the dropdown pipe in, set the drop length, and tighten both set screws fully." diagram="rail-03-ceiling-mount.svg" %}

{% include step.html number="2B" title="Beam or joist mount" body="Use this where the only solid surface is a vertical face. Drill a clearance hole for the perpendicular bracket's shaft, seat the shaft, and fasten the bracket flat to the surface. Slide the dropdown pipe in, set the drop length, and tighten both set screws fully." diagram="rail-03b-beam-mount.svg" %}

{% include step.html number="3" title="Attach the rail to the mounts" body="With a second person, raise the rail and line the pipes up to the mounts. Keep set screws on the same side for a clean look. Tighten the pipe set screws, then the T-nut screws on top of each block. Check the pipes are vertical, then shake the rail to confirm it's solid." diagram="rail-03-attach-rail.png" %}

## Other mounting methods

Hardware must connect to the rail through T-nuts. Beyond that, some sites need a different approach:

- A threaded rod instead of the dropdown pipe
- A U-bolt to attach unistrut to a pipe
- Mounting straight through a wood beam with no drop, using the longer flat-head screws, washers, and lock nuts
- An L-bracket to unistrut where rails run perpendicular to a wall

## Post-mount checks

{% include checklist.html items="All fasteners fully tightened | Rail level, drop pipes vertical | Rail height and location match the site plan | Rail swings no more than 1/4\" from rest in either direction" %}

{% include warn.html text="If the rail swings more than 1/4\", add aircraft cable or bracketing to stiffen the assembly before loading heaters." %}

## Plug in the rail

{% include dodont.html do="Plug directly into a dedicated, GFCI-protected outdoor outlet on its own circuit." dont="Use an extension cord, power strip, or a circuit shared with other loads." %}

Run the cable along the rail, up the mounting hardware, or along features of the space so it stays out of sight from diners and the street. Plug in, flip the rail switch on, and secure any slack so nothing hangs below the bottom of the rail.
